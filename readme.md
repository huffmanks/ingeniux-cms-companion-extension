# Ingeniux CMS Companion

A Chrome and Firefox extension that enhances Ingeniux CMS with live-site navigation, view controls and useful CMS shortcuts.

The extension detects the current asset or page context and provides quick access to the corresponding published page. It supports multiple publishing targets, allowing users to switch between different live environments (e.g., staging, production or multiple sites within the same CMS instance).

Additional tools include shortcuts for switching between CMS views, such as Full View and Tree View, along with configurable settings through the extension popup.
